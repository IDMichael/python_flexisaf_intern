# Basic Math CLI Calculator

## Description

This program is a command-line calculator that performs basic arithmetic operations: addition, subtraction, multiplication, and division. It validates user input, prevents division by zero, and continuously runs until the user chooses to exit.

## How to Run

1. Ensure both files are in the same directory:

   * `math_tools.py`
   * main script file (e.g., `main.py`)

2. Run the program:
python main.py


3. Follow the on-screen menu to select an operation and input numbers.

## Required Libraries

* No external libraries required (uses only Python built-in functions).
