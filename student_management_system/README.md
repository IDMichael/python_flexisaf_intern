# Student Manager System

A simple **Python console program** to help students manage their **tasks/assignments** and **daily expenses**. This program is entirely command-line based and does not require any external libraries.

---

## Features

### Task Manager
- Add new tasks/assignments.
- View all tasks with status (Done / Not Done).
- Mark tasks as completed.
- Update existing tasks.
- Delete tasks.

### Expense Tracker
- Add daily school-related expenses (e.g., lunch, transport, books).
- View all recorded expenses.
- Filter expenses by category.
- Show expenses above a certain amount.

---

## How to Run

1. Make sure you have **Python 3.x** installed.
2. Save the code into a file, e.g., `student_management_system.py`.
3. Open your terminal or command prompt.
4. Navigate to the directory containing `student_management_student.py`.
5. Run the program using:
python student_management_system.py
