### Student Contact Manager

## What the Program Does
The Student Contact Manager is a command-line Python program that allows a school administrator to:

+ Add new contacts (Student, Parent, Teacher, Staff)
+ Update existing contacts
+ Delete contacts
+ Search for a contact by Unique ID
+ List all saved contacts

# Each contact contains:
+ Unique ID
+ Full Name
+ Email Address (no duplicates allowed)
+ Phone Number (11 digits, no duplicates allowed)
+ Role

The program prevents duplicate emails and phone numbers using sets and stores all data in a dictionary.

## How to Run the Program

Step 1: Save the file as:
student_contact_manager.py

Step 2: Open your terminal or command prompt.

Step 3: Run:

python student_contact_manager.py

or

python3 student_contact_manager.py

The program will start and display the menu.

## Required Libraries

No external libraries are required.

The program uses only:

Python 3.x

Built-in data structures (dictionary, set, list)
