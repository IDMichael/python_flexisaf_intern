# Password Strength Checker

What the Program Does:

The Password Strength Checker evaluates the strength of a password entered by the user. It checks the password against the following criteria:

- Minimum length of 8 characters

- Contains lowercase letters

- Contains uppercase letters

- Contains numbers

- Contains special characters (e.g., `!@#$%^&*()-_=+[]{}|;:'",.<>/?~``)

Based on these checks, the program labels the password as Weak, Medium, or Strong. Users can repeatedly check multiple passwords until they choose to exit.

# How to Run

- Ensure Python 3 is installed on your system.

- Save the code as password_checker.py.

- Open a terminal or command prompt.

- Navigate to the folder containing password_checker.py.

- Run the program using the command:

python password_checker.py

Follow the prompts to enter a password. To exit, type q or quit.

# Required Libraries

sys (standard Python library, no installation required)

## Expense Tracker

What the Program Does:

- The Expense Tracker allows users to record, categorize, and track personal expenses. Users can:

- Enter the amount spent

- Select a category (Food, Rent, Beverage, Internet, Transport, Other)

- Add an optional note for the expense

- Add an optional date (defaults to today if not provided)

- The program summarizes all recorded expenses and calculates the total spent, as well as totals per category.

# How to Run

- Ensure Python 3 is installed on your system.

- Save the code as expense_tracker.py.

- Open a terminal or command prompt.

- Navigate to the folder containing expense_tracker.py.

- Run the program using the command:

python expense_tracker.py

Follow the prompts to enter your expenses. To exit at any point, type q or quit.

# Required Libraries

- sys (standard Python library, no installation required)

- datetime (standard Python library, no installation required)
