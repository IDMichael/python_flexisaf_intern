# CLI To-Do List Application

## What the Program Does
This is a Command Line Interface (CLI) To-Do List application written in Python.

The program allows a user to:
- Add a new task
- View all tasks
- Mark a task as done
- Delete a task
- Exit the application
Tasks are stored temporarily in memory while the program is running.

Each task contains:
- A title
- A completion status (Done or Not Done)

The program runs in a continuous loop until the user chooses to exit.

## How to Run the Program
1. Ensure Python Is Installed
Check your Python version:
python --version

or

python3 --version
Python 3.8 or higher is recommended.

2. Project Structure
Ensure both files are in the same folder:

main.py
todo_functions.py

3. Run the Application
In your terminal or command prompt, navigate to the folder containing the files and run:

python main.py

or

python3 main.py

The menu will appear, and you can begin interacting with the program.

## Required Libraries
This program uses only Python’s built-in features.
No external libraries or packages are required.

Python 3.x
